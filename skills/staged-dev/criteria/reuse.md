# 재사용 기준

이미 있는 것을 새로 만들지 않는다. 새 함수·타입·모듈을 만들기 전에 찾는다.

## 찾는 곳과 순서

1. 이 저장소의 기존 코드: 이름, 시그니처, 핵심 로직으로 찾는다.
2. 이미 설치된 의존성: 매니페스트·lockfile과 그 API.
3. 언어 표준 라이브러리.
4. 아직 설치되지 않은 외부 라이브러리: 이 프로젝트 언어의 패키지 저장소와 웹.

1~3에 있으면 그것을 쓰고 새로 만든 중복은 지운다. 확실한 근거(파일:줄, API 이름)가 있는 것만 같은 것으로 본다.

## 외부 라이브러리로 바꿀 가치

- 바꿀 만한 것: 규격이나 엣지케이스가 복잡해 직접 짜면 틀리기 쉬운 문제(CSV 파싱, 날짜·시간대, 암호화, URL·이메일 검증 등).
- 바꾸지 않을 것: 몇 줄짜리 단순 로직.
- 확인할 것: 최근 릴리스 시점, 사용량, 라이선스, 크기와 딸려오는 의존성, API가 이 작업에 맞는지.

새 외부 의존성을 들이는 것은 사람을 부르는 경우다(SKILL.md). 후보와 무엇을 대체하는지, 근거를 보이고 묻는다. 답을 기다리는 동안 다른 단위는 계속한다.
