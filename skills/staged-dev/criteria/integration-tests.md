# 통합 테스트 기준

- 컴포넌트는 실제로 연결한다. mock은 시스템 바깥(외부 서비스)에만 쓴다.
- 수용 기준마다 사용자 관점에서 입력부터 최종 결과까지 확인하는 시나리오를 하나씩 만든다.
- 단위 테스트에서 이미 검증한 세부 분기는 반복하지 않는다.
- 환경 준비와 정리는 테스트 안에서 자동으로 처리한다. 사람이 손으로 할 단계가 있으면 안 된다.

## 모드별 목표

- build, extend: 수용 기준(acceptanceCriteria) 각각을 끝에서 끝까지 검증한다.
- refactor: 바꾸기 전과 외부 동작이 끝에서 끝까지 같은지 검증한다. 가능하면 변경 전 커밋에서도 같은 테스트가 통과하는지 확인한다.
